# UI / UX Polish — Brief

Found by using the app in a 390×844 mobile browser with realistic data. Goal: feel like a polished native travel app, glanceable mid-trip, one-handed.

## Design system (Task A)

- Icons: inline SVG set in `components/ui/icons.tsx` (stroke 1.75, `currentColor`, 24px default): calendar, map-pin, bed (stays), map, plus, chevron-left/right/down, navigation (directions arrow), more (⋯), pencil, trash, search, x, clock, note, grip/reorder, tag, external-link, logout, locate. No icon library.
- Bottom nav: SVG icons + labels, active = red-500 icon+label with small pill background; inactive zinc-500. Keep 4 tabs.
- Surfaces: page bg `zinc-950`; cards `bg-zinc-900 ring-1 ring-white/5 rounded-2xl`; section headings `text-xs font-semibold uppercase tracking-wider text-zinc-500`; primary text zinc-100, secondary zinc-400.
- Header: large title style on top-level tabs (text-2xl bold), compact title with back button on detail pages; actions as 44px icon buttons (SVG, not emoji/“+” glyph).
- Primary floating action button (FAB) component: 56px red-500 circle with plus icon, fixed bottom-right above the bottom nav + safe area; used for "add" on Days, Day detail, Locations, Stays (replaces header "+" on those screens).
- Location action button: `DirectionsButton` (navigation SVG in a 44px round zinc-800 button, aria-label "Open in Google Maps") replaces the 📍 emoji buttons in lists. Full-width variant keeps label "Directions".
- Data freshness: sync on every route change and window focus with a 30 s throttle (was 5 min); a 304 costs ~200 B.

## Days (Task B)

- Days list:
  - Trip header card: before trip "Trip starts in N days · <first date> – <last date>"; during trip "Day X of N" and a "Today" button jumping to today's day; after trip "Trip complete".
  - Each day card: left date block (weekday small, day number big), "Day N" label, title, hotel for that night (bed icon), first 2–3 item previews (time + emoji + name, or note text), "+N more".
  - Gaps between non-consecutive dates shown as a thin divider "2 days without plans".
  - Log out moves to a "⋯" header menu sheet (with "Categories" and "Log out").
- Day detail:
  - Header: back, date title, prev/next day chevrons (disabled at ends), edit (pencil). Horizontal swipe left/right on the content also goes to next/previous day.
  - Hero: "Day N" + title, day note callout, hotel card (bed icon, name, "Night 2 of 4", Directions + Airbnb buttons).
  - Section labels "Schedule" (timed) and "Anytime" (untimed).
  - Schedule rendered as a vertical timeline: time column on the left, dot + connecting line, item card on the right (emoji, name, city/area, note callout, Directions button).
  - Area items: whole row tappable to expand; clear chevron-down that rotates; places listed indented with Directions buttons.
  - Reorder: "Reorder" text button on the Anytime heading toggles reorder mode showing ↑/↓ controls; hidden otherwise.
  - FAB "+" opens the add sheet directly on the location picker, with a prominent "Add a note instead" row at the top (no separate chooser step).
  - Empty day: friendly empty state with "Add a place" button.

## Locations (Task C)

- List:
  - Single compact filter bar: search field with search icon; below it one horizontally scrolling chip row: All / Areas / Places, then a divider, then city chips (from data), then a "Category ▾" chip opening a small sheet of categories. Removes the two selects.
  - Group list by city with sticky city headers ("TOKYO · 6").
  - Rows: emoji tile, name, secondary line (category · in <Area>); show an "Area" chip only for areas (no "Place" chip); Directions button.
  - Header actions: tag icon button labeled for screen readers "Categories" plus visible text "Categories" in the ⋯ sheet; FAB for add.
- Detail:
  - Hero: large emoji tile, name, chips (Area/Place, category, city).
  - Primary row: Directions (full width, red) + Edit (secondary).
  - "Planned on" section (reuse `plannedOn` from `lib/map-data.ts`) with tappable day rows.
  - Areas: "Places here" list + "Add place here".
  - Delete as a subtle red text button at the bottom ("Delete location"), still via ConfirmDeleteDialog.
- Form:
  - Order: Type (Area/Place) → "Paste Google Maps link" (first, with helper text "Share → Copy link in Google Maps") → Name → City → Area (places) → Category → Emoji (quick-pick row of ~12 common travel emoji + text input) → Description → Lat/Lng in a collapsed "Coordinates" disclosure (auto-opened if paste fails).

## Stays & Map (Task D)

- Stays: vertical timeline of stays with date range bar, "Now"/"Upcoming"/"Past" states, nights count, Directions + Airbnb buttons; gaps between stays shown ("No stay booked Oct 24 – 25" warning in amber — useful catch). FAB for add.
- Map: attribution starts collapsed (compact "i" only); locate button + attribution never overlap; chips row gets a subtle top gradient for legibility.

## Out of scope

Data model changes, new features beyond the above, light theme.
